# 🧮 계산 노트 (CalcNote)

감정평가 업무용 **엑셀식 사칙연산 계산기**. 윈도우에서 프로그램처럼 실행하는 독립 앱입니다 (인터넷 불필요).

## 설치 (윈도우 노트북)

1. 이 저장소에서 **Code → Download ZIP**을 받거나, `calc.html`과 `계산노트 실행.bat` 두 파일을 받는다.
2. 두 파일을 **같은 폴더**에 둔다 (예: `문서\계산노트`).
3. **`계산노트 실행.bat` 더블클릭** → 주소창 없는 앱 창으로 열림.
4. 바탕화면 아이콘을 원하면: bat 파일 우클릭 → 보내기 → **바탕 화면에 바로 가기 만들기**.

## 주요 기능

- 셀에 숫자·메모·수식(`=B2*C2`) 입력 — 사칙연산 전용(+ − × ÷, 괄호), 함수 없음
- 수식 입력 중 다른 칸을 클릭하면 그 칸 주소가 자동 삽입
- `70억` `3,500만` `1.5억` `5%` 같은 한글 단위 숫자 입력, 결과는 하단에 억/만 병기
- 계산 시트 자동 저장·목록화 → 과거 계산을 다시 열어 수정·재사용
- 내장 양식: **거래사례 비준표** / **토지·건물 일괄사례 배분**(거래총액 − 건물가격 ÷ 토지면적 = 토지단가)
- `Ctrl+C/V` 셀 복사(수식 상대참조 이동) · `Ctrl+Z` 되돌리기 · 열너비 드래그 · 💾 백업/복원(.json)

## 데이터 보관 주의

계산 기록은 이 컴퓨터의 브라우저 저장공간에 남습니다. **브라우저 "인터넷 사용 기록 삭제"(쿠키·사이트 데이터)를 하면 기록이 지워지므로**, 가끔 앱의 **💾 백업** 버튼으로 .json 파일을 저장해 두세요. 다른 컴퓨터로 옮길 때도 백업 → 복원을 쓰면 됩니다.
