# 🧮 계산 노트 (CalcNote)

감정평가 업무용 **줄노트식 사칙연산 계산기** (스피드크런치 스타일). 윈도우에서 프로그램처럼 실행하는 독립 앱입니다 (인터넷 불필요).

## 설치 (윈도우 노트북)

1. 이 저장소에서 **Code → Download ZIP**을 받는다 (`calc.html`, `server.ps1`, `계산노트 실행.bat` 3개 필요).
2. 세 파일을 **같은 폴더**에 둔다 (예: `문서\계산노트`).
3. **`계산노트 실행.bat` 더블클릭** → 주소창 없는 앱 창으로 열림.
4. 바탕화면 아이콘을 원하면: bat 파일 우클릭 → 보내기 → **바탕 화면에 바로 가기 만들기**.

## 주요 기능

- 한 줄에 산식을 치면 오른쪽에 결과가 즉시 표시 — `1,200,000*84.97`, 사칙연산 전용(+ − × ÷, 괄호)
- `건물가격 = 80만*1,250`처럼 **이름을 붙이면 아랫줄 계산에 재사용** (`거래총액-건물가격`). `ans` = 바로 위 결과
- `70억` `3,500만` `1.5억` `5%` 같은 한글 단위 숫자 입력, 결과 옆에 억/만 병기
- 윗줄 숫자를 고치면 아랫줄이 전부 자동 재계산 — 과거 계산도 열어서 수정·재사용
- `#`으로 시작하면 제목 메모, 계산 안 되는 글은 자동 회색 메모
- 내장 양식: **거래사례 비준** / **토지·건물 일괄사례 배분**(거래총액 − 건물가격 ÷ 토지면적 = 토지단가)
- Enter 새 줄 · ↑↓ 줄 이동 · 빈 줄 Backspace 줄 삭제 · 결과 숫자 클릭 시 편집 줄에 값 삽입 · 💾 백업/복원(.json)

## 데이터 보관 (파일 저장)

`계산노트 실행.bat`으로 열면 계산 기록이 **앱 폴더의 `계산노트기록.json` 파일**에 저장됩니다 (직전 상태는 `계산노트기록.이전본.json`에 1개 보관).

- 브라우저 "인터넷 사용 기록 삭제"를 해도 기록이 안전합니다.
- 백업/이동 = 이 파일을 복사하면 끝. 다른 컴퓨터에서는 앱의 **복원** 버튼이나 파일 복사로 이어서 쓸 수 있습니다.
- `calc.html`을 bat 없이 직접 더블클릭하면 파일 저장 없이 브라우저 저장으로만 동작합니다(하단 상태표시로 구분 가능 — "기록파일에 저장됨"이 떠야 파일 저장 중).

구성 파일: `calc.html`(앱) + `server.ps1`(기록 도우미 — bat이 자동 실행) + `계산노트 실행.bat`(실행기).
